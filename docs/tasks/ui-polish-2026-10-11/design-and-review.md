# DawnKB 界面精修 · 2026-10-11

## 设计说明

用户需要浏览知识之间的关系、找到文档继续阅读，并在同一工作台积累笔记。沿用现有 DawnKB 的浅色纸面、紫色强调、中文衬线标题与 Lucide 图标，不做方向重选。总览以知识网络为主角，数据与最近内容辅助；书架的主动作是继续阅读，素材层的主动作是浏览目录和打开文档。

本轮从共享样式与导航源头调整，覆盖总览、书架、素材层、设置，并检查知识图谱、随手记、题库机和头脑风暴的共享导航表现。

- 提高数据标签、文件标题、路径、日期、表单说明与检索输入的字号；中文主标题行高改为 1.25。
- 导航按知识空间、每日积累、AI 工作区分组，删去每行重复的小提示；提示仍可从悬停标题读取。短窗口允许导航区域滚动。
- 总览图谱填满所属区域，图例与底部统计独立预留空间；手机列表允许长名称换行。
- 按钮按下立即轻微下沉与缩放；当前导航的紫色底板随路由移动；总览内容按阅读顺序短暂进入。延续原有搜索面板入场。
- 图谱节点呼吸从无限循环改为一次，保留已有蜘蛛陪伴角色。支持系统减少动态效果。
- 素材类型图标统一为现有 Lucide；卡片预览隐藏 HTML/生成注释与 Excalidraw 插件说明。原文内容不变。
- 增加键盘跳转到主内容的入口、菜单展开状态语义，修复暗色主按钮的文字颜色。

没有新制图片或接入素材服务：现有知识图谱与角色已经承担识别作用。未增加第三方依赖。

## 减法记录

- 总览长介绍缩为“浏览知识之间的联系，接着上次的阅读与积累。”
- 书架介绍缩为“接着上次读到的地方，让值得留下的内容变成笔记。”
- 删除导航行右侧的重复提示，保留导航名称与悬停提示。
- “MARKDOWN 文档”“WIKILINKS”改为“知识文档”“文档链接”。
- 删除文件夹条目左侧的彩色描边，保留识别文件夹用的图标颜色。
- 隐藏卡片摘要中的生成注释与绘图插件操作说明。
