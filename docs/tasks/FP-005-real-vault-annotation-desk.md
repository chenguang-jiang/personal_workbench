# FP-005 真实 Vault 浏览与阅读批注台

## 状态

Done

## 目标

素材层按已配置的 Obsidian Vault 真实目录逐级浏览，不再用文章类型模拟文件夹；阅读器把“笔记 / 理解 / 入库”收拢到同一上下文中，并允许用户明确选择现有 Vault 目录写入新的 Markdown 笔记。

## 前端实现

- `/dashboard/library` 从 `/api/obsidian/library` 读取真实目录、递归文件数量、子目录数量和当前目录文件；支持面包屑、返回上级与文章直达。
- 选中文本浮窗调整为“理解 / 高亮 / 笔记 / 入库”，三个知识动作共享当前引用和附近上下文。
- 阅读批注台包含“笔记 / 理解 / 入库”三个页签；桌面端为右侧工作台，移动端为全宽面板。
- 笔记支持全文笔记与带引用的段落批注；理解支持快捷问题、流式答案和“保存为笔记”。
- 入库前展示目标目录、标题和打包内容；已有 Obsidian 原文默认只建立引用，不重复存档全文。

## 后端实现

- `src/lib/obsidian-vault.ts` 负责 Vault 路径约束、真实目录统计和 Markdown 元数据读取。
- `GET /api/obsidian/library` 返回当前目录、面包屑、子目录与文件；`mode=folders` 返回可供入库选择的目录。
- `POST /api/obsidian/ingest` 仅允许写入配置的 Vault 内部，使用新文件名避免覆盖，并在成功写入后立即执行增量同步。
- AI 理解接口接收用户问题、选中文本、附近上下文和截断后的全文；问题不再被选中文本覆盖。
- 仅当 Vault 没有任何可见目录时创建 `00-Inbox / 阅读资料 / 知识笔记` 默认目录；已有目录结构保持不变。
