## 1. 总体策略

### 1.1 首版 MVP — 只跑通一条完整链路

> **导入文章 → 阅读 → 高亮/笔记 → AI 解释 → 自动进入素材库 → 搜索复用**

这条链路覆盖了项目最有辨识度的能力（阅读器 + AI + 知识沉淀）。跑通后再扩展。

### 1.2 MVP 范围与非目标

| 范围内（MVP） | 暂不做（非目标） |
|---------------|-----------------|
| 文章导入（手动粘贴 / Markdown） | RSS 自动抓取 |
| 阅读器（渲染 / 选中 / 高亮 / 笔记） | 知识图谱可视化 |
| AI 解释 / 翻译 / 总结（本地 Ollama） | 评论区聚合 |
| 素材库列表 + 搜索 + 标签筛选 | 跨平台数据看板 |
| 阅读进度追踪 | 每日精读推荐算法 |
| 本地 PostgreSQL + 本地 Ollama | 多用户认证 |
| | Vercel / 云端部署 |
| | 多平台评论采集（爬虫/模拟登录） |

### 1.3 状态定义（五态）

每个任务不再是二值复选框，而是五态：

| 状态 | 含义 |
|------|------|
| ⬜ 未开始 | 尚未动工 |
| 🏗 页面骨架 | 路由和 UI 占位存在，无数据交互 |
| 🔌 数据接通 | API 已对接，可 CRUD，但交互未打磨 |
| ✅ 可用 | 核心功能可用，能完成预期操作 |
| 🔍 已验收 | 通过验收标准（Given/When/Then），边界情况覆盖 |

### 4.2 阅读器验收标准（Given / When / Then）

| # | Given | When | Then |
|---|-------|------|------|
| V1 | 文章列表页已加载 | 点击"新建文章"，填入标题和正文，点击保存 | 跳转到阅读器，正文正确渲染 |
| V2 | 阅读器中正文已加载 | 选中一段文本（≥2 字） | 弹出浮窗，含"理解 / 高亮 / 笔记 / 入库" |
| V3 | 浮窗已弹出 | 点击"理解"并输入问题 | 批注台保留引用并流式返回针对问题的答案 |
| V4 | 浮窗已弹出 | 点击"高亮"，选颜色 | 选中文字被着色，数据库保存高亮记录 |
| V5 | 浮窗已弹出 | 点击"笔记"，输入文字，保存 | 高亮 + 笔记保存，笔记侧栏显示 |
| V6 | 阅读器中滚动正文 | 滚动到 50% 位置 | 顶部进度条显示 50%，1 秒后持久化 |
| V7 | 关闭浏览器后重新打开文章 | 再次进入 | 阅读进度恢复，高亮标注仍在 |
| V8 | 阅读器中选中跨段文本 | 选中文本 | 浮窗正常弹出，高亮包裹不报错 |
| V9 | AI 未配置 API Key 且 Ollama 未启动 | 点击"AI 解释" | 返回明确错误提示，不白屏 |
| V10 | 文章正文含 Markdown 标题/列表/引用 | 渲染 | 正确转换为 HTML |
| V11 | 理解回答已生成 | 点击"保存为笔记" | 引用、问题和回答写入当前文章笔记 |
| V12 | 入库页签已打开 | 选择已有 Vault 文件夹并确认 | 新 Markdown 写入该目录且不覆盖同名文件 |

## 10. 开发规范

### 10.1 技术版本锁定

| 技术 | 锁定版本 | 说明 |
|------|---------|------|
| Node.js | ≥ 18（推荐 20+） | |
| Next.js | 16.3.0 | App Router，Turbopack |
| React | 19.2.8 | |
| Tailwind CSS | v4 | `@theme` 语法，无 config 文件 |
| Prisma | 7.9.1 | adapter 模式，config 在 `prisma.config.ts` |
| PostgreSQL | 17（Orbstack 容器） | 端口 5433 |
| Zustand | 5.x | 状态管理 |
| AI SDK | 7.x | `streamText` + `toTextStreamResponse` |

### 10.2 本地部署架构

```
┌─────────────────────────────┐
│  浏览器 (localhost:3000)     │
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│  Next.js dev server          │
│  (npm run dev)               │
│  前端 + API Routes            │
└──────┬───────────────┬──────┘
       │               │
┌──────▼──────┐  ┌─────▼──────┐
│ PostgreSQL  │  │ Ollama     │
│ (Orbstack)  │  │ (本地)     │
│ :5433       │  │ :11434     │
└─────────────┘  └────────────┘
```

**不做 Vercel 部署。** 所有服务跑在本地：
- Next.js → `localhost:3000`
- PostgreSQL → Orbstack 容器 `localhost:5433`
- Ollama → `localhost:11434`（AI 功能可选）

### 10.3 Commit 规范

```
feat: 新增功能
fix: 修复 bug
docs: 文档更新
refactor: 重构
chore: 构建/依赖
```

### 10.4 npm 脚本

```bash
npm run dev          # 启动开发服务器
npm run build        # 生产构建
npm run db:migrate   # 数据库迁移
npm run db:generate  # 生成 Prisma Client
npm run db:seed      # 种子数据
npm run db:studio    # Prisma Studio
```
