# 录屏视觉、动效与功能整理

## 1. 视觉语言

- **整体气质**：浅色、克制、编辑部/研究工作台风格。大面积留白配合细边框和紧凑的数据区域，不依赖阴影堆叠层级。
- **主色**：高明度中性背景，正文近黑；紫色只用于当前导航、智能状态、关键数字和主要动作；绿色表示在线或同步成功。
- **字体层级**：页面名称使用中文衬线大标题；导航、正文和表单使用清晰的无衬线字体；章节提示与数据标签使用小号等宽英文。
- **布局**：桌面端固定左侧导航，右侧为内容画布；内容区常使用“主任务 + 右侧状态/助手”的非对称双栏结构。
- **组件**：细边框、8–12px 圆角、低对比背景；按钮以黑色或紫色实心为主，次要操作使用白底描边。

## 2. 动画与交互反馈

- 页面切换保持快速，不做整页编排动画；内容通过 150–240ms 的淡入和短距离位移完成状态过渡。
- 左侧当前导航使用淡紫背景切换，图标和文字同步变色。
- 数据格、文件夹行、书籍和证据卡在悬停时改变背景、边框或轻微抬升，不使用弹跳。
- 知识图谱节点缓慢呼吸，选中节点放大并显示连线或详情；拖拽/缩放用于探索关系。
- 阅读器右侧助手采用面板内标签切换；“笔记 / 解释 / 入库”在当前阅读上下文内完成。
- 顶部智能状态、同步状态和刷新状态使用小圆点、轻量旋转或脉冲表达。
- 所有持续动画在 `prefers-reduced-motion` 下关闭或降级为瞬时状态变化。

## 3. 录屏中的功能结构

1. **工作台总览**：内容数量、知识图谱预览、生产动态、知识健康度、最近更新与全局搜索。
2. **知识图谱**：节点搜索、类型过滤、关联内容列表、节点详情和进入原文。
3. **素材层**：待阅读队列、真实文件夹浏览、全文检索、文件状态与入库入口。
4. **阅读器**：长文阅读、选中文字、解释、笔记、高亮和资料打包入库。
5. **书架**：当前阅读、阅读进度、书籍卡片和继续上次位置。
6. **知识头脑风暴**：基于知识库与当前认知提出问题，保留会话历史和结论。
7. **每日热点**：外部信号聚合、必读推荐、刷新和稍后阅读。
8. **社媒洞察**：评论/回复/证据聚合、筛选、详情分析和转为选题。
9. **平台数据**：核心指标、内容线贡献、体裁贡献、作品明细和趋势复盘。

### 新增识别

- **评论不是终点**：录屏先展示评论证据列表，再进入主题卡片；主题详情必须保留代表原话、平台和情感，结论需要可追溯。
- **数据需要钻取**：平台数据先用连续指标带建立口径，再用 30 天趋势和内容贡献定位异常；点击作品后进入历史曲线弹窗，而不是只看静态总数。
- **书架需要封面层级**：当前阅读占据独立横幅，其他文章以封面进入；大量文章不能在同一页无限展开。
- **字体角色更明确**：页面标题和书名使用宋体/衬线；正文和控件使用清晰无衬线；来源、日期、指标单位继续使用等宽字体。
- **动效集中在状态变化**：主题切换淡入、证据脊线从底部生长、图表指标切换重绘、作品详情短距离放大进入；不增加装饰性持续动画。
